## 软连接方案完整工作流（最终版）
- 新增 skill：cd /Users/xuke/Skill/AndroidSkills/skills/<新目录>/ → 写 SKILL.md → `git add . && git commit`，post-commit hook 自动重链 + 清断链；或手动 `cd AndroidSkills && sh setup.sh` 立刻装。
- 修改 skill：直接编辑 AndroidSkills/skills/<某>/SKILL.md，5 个全局目录自动同步，零延迟。
- 删除 skill：`cd AndroidSkills && git rm skills/<某> && git commit`，hook 重链时 prune 自动清掉软连接。
- 验证软连接：`sh scripts/list.sh --agent all`；抽样 `readlink ~/.claude/skills/<某>`。
- 卸载全部：`sh setup.sh uninstall all`（或单独 `sh setup.sh uninstall <agent>`）。
