# 多年双块真题 + 答案 -> Excel 题库

## 触发场景
- 用户上传真题 PDF，内容结构为：**前半部分是各年份题目，后半部分按相同年份顺序给出答案**（年份在文中重复出现两遍）。
- 典型文件：各高校「历年真题及答案」合集（如吉林师范大学 816 课程与教学论 2013–2023 合集，110 页）。

## 与 exam-processor 的关系
- exam-processor 处理单份/单年真题（题目与答案混排或题目自带答案）。本技能是其**补充**，专门处理题目块与答案块分离的多年合集。
- 输出字段与 exam-processor 完全一致：`ID, 题目, 题型, 分数, 难度, 选项A–E, 答案, 解析, 一级目录, 二级目录`。

## 解析流程（PyMuPDF 提取全文后）
1. **不要**在导出文本里插入 `=== 第N页 ===` 之类的分页标记；若已插入，必须当作噪音行过滤（否则会混进题干/解析）。
2. **切分题目块 / 答案块**
   - 题目块题型标题带序号：`^[一二三四五六七八九十]+[、.．]\s*(.+)$`
   - 答案块题型标题无序号：`^(名词解释|简答|简答题|论述|论述题)\s*[：:]?\s*$`
   - 边界 = 第一个满足「年份行 `^\d{4}\s*年`，且其下一个非空非噪音行匹配**答案块题型标题**」的年份行；该年份行之前为题目块，之后为答案块（题目块标题带"一、"不会误判）。
3. **题目块解析**：年份行重置；题型标题行 `sec_order += 1`；`^\d+[.．、]\s*(.+)` 开新题，续行追加；用 `fold()` 折叠跨页换行并清理 CJK 间空格、分页页码、页眉广告（企业QQ）。
4. **答案块解析**：
   - 题型标题行**直接建 section**，**不要**要求「下一行是题号」——论述首题常无 `1.` 直接写题干（如「系统性与循序渐进相统一的原则。」），否则该题型整段会并入上一题型。维护 `last_anum`，切换 section 时归零。
   - `^\d+[.．、]\s*` 开新答案，`a_num`=题号；若当前 section 尚无题且遇到普通正文行，自动 `a_num = last_anum+1`（处理无题号首题）。
   - 每年题型顺序与题目块一致，`sec_order` 对齐。
5. **配对**：`(year, sec_order, q_num)` 一一对应。题目块 `q_num` 来自题号；答案块 `a_num` 来自题号或自动编号。
6. **清理答案文本**：
   - `Q_RE` 已剥离 `1.` 题号；再用 `^[^：:\n]{1,30}[：:]\s*` 去掉「题名：」前缀（如「校本课程：」）。
   - 折叠换行、去 CJK 间空格、去分页页码/广告。
7. **回填「同YY年」占位**：源资料常用「同13年」指代复用往年同名题答案。构建 `by_year = {year: [(二级目录, 题目, 解析)]}`；对含 `同\s*\d{1,2}\s*年` 的解析，在被引用年份（2000+YY）找**题目文本去标点后精确相等**的题回填完整解析；找不到则保留占位并提示用户。

## 题型字段映射
- 名词解释/简答/论述/案例分析/判断说理等 → 题型列填「问答题」，二级目录保留具体题型名。
- 一级目录格式：`{两位年}年{学校}{科目}`，如 `13年吉林师范大学816`。

## 陷阱清单
- 答案块题型标题确认若要求「后接题号」，无题号首题（论述常见）会被并入上一题型 → 题数膨胀、后续 section 错位。
- 导出分页标记未过滤 → 混入题干/解析。
- **保持用户原题文字不变**（即使源 PDF 有错字，如「循序渐近性」应为「循序渐进」），仅在交付时提醒，不擅自改写。

## 依赖
- `pymupdf`(fitz) + `pandas` + `openpyxl`，装在隔离 venv（如 `/Users/xuke/.workbuddy/binaries/python/envs/exam`）。

## 校验要点（交付前必做）
- 打印每年「题目块题型/题数 vs 答案块题型/题数」是否一致；不一致处（如某年简答题目4道但答案5道）要向用户说明。
- 全局扫描解析是否残留页码标记、页眉广告、题型标题行、未去除的「题名：」前缀。
- 确认所有题目均匹配到答案（除明确的「同YY年」无法回填者）。
