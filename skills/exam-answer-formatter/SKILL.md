# 论述题答案规范化排版

将一段考试论述题/简答题答案，按以下四项规则统一排版后输出。**不改变原句意思、不重组论证结构、不大改语句。**

## 适用场景

- 用户提供一段论述题/简答题答案，要求统一格式、修正错别字、统一标点。
- 典型不规范输入：`(1 )`（半角括号带空格）、英文逗号 `,`、标点后多余空格、`- 小点` 并列项、少量错别字（如「囫囫囵吞枣」「切已体察」）。

## 工作流程

### 1. 修正错别字（仅 AI 判断）
逐句检查并**直接修正**错别字，**不改变句子原意、不重组结构**。考试文本通常只有少数错别字。常见示例：
- 「囫囫囵吞枣」→「囫囵吞枣」
- 「切已体察」→「切己体察」（「已」误作「己」，注意与「自己」区分）

修正时保持原词原句，只改错字；无法确定的保留并提示用户。

### 2. 统一序号格式
将半角序号统一为全角中文括号、内部无空格：
- `(1 )` / `( 2)` / `(3)` → `（1）` / `（2）` / `（3）`
- 大序号一律使用 `（数字）` 形式，数字前后不留空格。

### 3. 统一标点（全中文、无中英混排）
全文仅使用中文标点，禁止英文标点。建议先运行 `scripts/normalize_punct.py` 做机械归一化首遍，再人工核对：
- 英文 `,` `;` `:` `!` `?` → 中文 `，；：！？`
- 半角 `()` → 全角 `（）`
- 删除中文/全角标点后的多余空格（如 `， ` → `，`）
- 删除数字与中文单位间的空格（如 `6 分` → `6分`）
- 若某处引号、句号为英文标点，也改为中文 `""` `。`
- **最终通篇不得同时含有英文与中文标点**（逗号、顿号、句号、引号、括号、冒号、分号等）。

### 4. 短横小点 → 圆圈序号
将文中以 `- ` 起始的并列小点，统一改为圆圈序号 `① ② ③ …`：
- 每个 `- xxx` 并列项依次换为 `①` `②` `③`。
- 仅转换原文以短横 `-` 起始的小点；无短横的段落（如作为引入的段落）保持原样，除非用户明确要求全部编号。

### 5. 输出
- 直接返回排版后的**完整文本**（不省略、不改写原意）。
- 同时将结果写入工作区一个 `.txt` 文件，并用 `present_files` 呈现，方便用户复制。
- 回复中用简短列表说明：修正了哪些错别字、序号/标点如何统一、短横转为哪些圆圈序号。
- 遇到歧义（如某段是否该加圆圈序号），在说明中提示并给出选项。

## 注意事项

- 严禁改变原句意思与论证结构。
- 错别字修正要保守：只在确有把握时修改，不确定的保留并提示。
- 圆圈序号仅用于并列的短横小点，不要给非并列主段落随意加号。
