# 范例：Before / After

以下用「朱子读书法」论述题答案演示本技能的四项规则。阅读此范例以对齐格式预期。

## Before（原始不规范文本）

```
(1 ) “朱子读书法”
①循序渐进: 其一, 读书应按一定次序, 不要颠倒; 其二, 根据自己的实际情况和能力， 安排读书计划, 并切实遵守; 其三, 读书要扎实打好基础, 不可囫囫囵吞枣, 急于求成。 熟读精思: 读书既要熟读成诵, 又要精于思考, 读书时必须多读、记住、背熟。对于所读之书, 要通过思考, 理解精深。精思就是从无疑到有疑再到解疑的过程。
②虚心涵泳;“虚心”指读书时要虚怀若谷, 静心思虑, 仔细体会书中的意思, 不先入为主, 牵强附会; 所谓“涵泳”， 是指读书时要反复咀嚼, 细心玩味。
③切已体察: 读书不能仅停留在书本、口头上， 而必须见于实际行动, 要身体力行。
④着紧用力: 其一, 必须抓紧时间, 发愤忘食， 反对悠悠然; 其二, 必须抖擞精神, 勇猛奋发, 切忌松松垮垮。
⑤居敬持志;“居敬”指读书时精神专一, 注意力集中;“持志”指要树立远大志向、高尚目标, 并以顽强的毅力长期坚持。
(“朱子读书法”; 共6 分，六点，1 分/点)

(2 ) 对当今阅读教学的启示

遵循认知规律。阅读要循序渐进, 按一定次序进行, 不可颠倒, 并根据实际能力安排计划。同时, 阅读教学的开展还应尊重学生身心发展的阶段性, 扎实打好基础, 避免揠苗助长或急于求成的“超前教育"。

- 引导深度阅读。要遵循“熟读精思”与“虚心涵泳”的方法, 阅读不应停留在背诵， 而应经历“从无疑到有疑再到解疑”的过程。教师应引导学生反复咀嚼文本, 在主动探究把握知识的深层意蕴。
- 强调思行结合。结合“切已体察”方法来看, 读书不能仅停留在书本和口头上， 而必须身体力行, 见之于实际行动。当代阅读教学应引导学生将书中的道理与自身经验及现实生活相结合, 实现“学思行”的统一。
- 培养专注品质。按照朱熹的“居敬持志”与“着紧用力” 方法, 读书时精神要专一、注意力应高度集中, 并保持抖擞发愤的精神状态。 教师应注重培养学生专心致志的阅读习惯, 引导其树立高尚的阅读目标, 并以顽强的毅力长期坚持。
(启示: 共9分,至少三点，6分/点)

总之, “朱子读书法”虽产生于古代, 但其关于读书次序、知行关系等阅读经验的论述， 依然是当今培养学生阅读能力和素养的重要参考。
```
